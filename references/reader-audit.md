# 独立读者审查

## 审查目的

以仅掌握所属大领域通用知识、未参与当前项目的读者身份阅读成稿。识别作者因掌握项目背景而忽略的语言障碍、知识缺口、指代歧义和信息顺序问题。

## 独立性要求

独立读者 agent 只能接收待审成稿和本文件中的任务说明，不得接收以下内容：

- 原始实验记录、代码、配置、术语表或旧报告；
- 作者准备表达的含义或预期结论；
- 当前 agent 已发现的问题、修改方案或预期答案；
- 前一次独立审查的意见。

不要利用文件夹中的其他材料补全报告。不要假设读者了解项目历史、内部命名或未在正文定义的缩写。

## 审查任务

严格按照报告的实际阅读顺序逐段审查。遇到以下问题时立即记录首次出现位置：

1. **语言结构**：句子缺少明确主语、谓语或作用对象；修饰关系不清；一个句子承担多个判断。
2. **名词堆叠**：多个项目概念、动作名词、评价维度或研究目的连续组成长名词串，无法立即识别中心词及各成分关系。
3. **空泛称呼**：“相关内容、相关情况、有关方面、该问题、这种方式、其他工作”等没有给出具体对象、范围或名称。
4. **长难句**：句子包含多层定语、多个条件、连续动作、因果链或过多并列项，首次阅读无法稳定划分关系。
5. **指代关系**：“其、该、此、上述、前者、后者、二者、相关、相应、这”等存在多个候选对象，或需要跨段落回溯。
6. **知识前提**：项目专有概念、缩写、变量、数据子集、指标、方法步骤或比较条件在首次使用前没有解释。
7. **信息顺序**：理解当前结论、图或表需要阅读后文；定义距离首次使用过远；公共设置与局部设置关系不清。
8. **比较表述**：比较双方、基线、实验条件、指标、单位、统计方式或重复次数不明确。
9. **图表表述**：表题、列名、图题或正文引用无法独立说明对象和含义；单元格使用叙述性判断。
10. **结论范围**：结论强度超过现有数据集、样本量、重复次数或统计证据。
11. **总结内容**：总结引入正文没有说明的新术语、新缩写、新数据或新结论。

不要根据专业经验替作者猜测含义。出现两种以上合理解释时，按歧义处理。

## 严重程度

- **阻断**：无法确定句子、段落、图表或结论的基本含义，继续阅读也无法可靠补全。
- **主要**：可以猜测大意，但需要回读、依赖项目知识或在多个解释中选择。
- **轻微**：含义基本明确，表达仍可更直接、凝练或符合中文习惯。

## 输出格式

先给出一句总体判断，再按首次出现顺序输出问题表：

| 位置 | 原文片段 | 严重程度 | 困惑类型 | 读者的具体疑问 | 最小修改建议 |
|---|---|---|---|---|---|

要求：

- “位置”写明章节、段落、图号或表号；
- “原文片段”引用足以定位的最短文本；
- “读者的具体疑问”使用第一人称说明无法确定的对象或关系；
- “最小修改建议”只说明需要补充、拆分、前移或改名的内容，不补造事实；
- 同一问题只在首次造成理解中断的位置记录；
- 没有发现问题时明确写明“未发现阻断、主要或轻微问题”。

表格后分别列出：

1. 阻断问题数量；
2. 主要问题数量；
3. 轻微问题数量；
4. 最早出现的理解中断位置；
5. 是否可以交付：仅在不存在阻断和主要问题时回答“可以”。

## 修订与复审

主 agent 根据审查表修订报告，保持所有实验事实和数值不变。缺少必要信息时使用 `[待补充：具体字段]`，不得自行补全。

存在阻断或主要问题时，修订后将新稿交给另一个新的独立 agent。新 agent 仍只接收新稿和本文件，不接收前次意见。重复审查，直至不存在阻断和主要问题。
