# 报告结构选择

根据材料规模和用户任务选择最轻量的结构。结果始终早于详细理论。

## 短篇实验进展

适用于一至三页的单项实验更新。

1. 标题
2. 阶段结论
3. 关键结果
4. 实验设置
5. 结果分析
6. 下一步工作

“阶段结论”用一个段落交代问题、方法、关键数值和结论范围。理论内容并入实验设置或结果分析。

## 专题研究报告

适用于方法、公式、多个实验或多个数据集构成的报告。

1. 标题
2. 摘要
3. 关键结果
4. 实验设置
5. 方法说明
6. 分组实验结果
7. 综合分析
8. 下一步工作
9. 参考文献

方法说明只保留理解实验所需内容。每组实验先给结果，再给对应设置和解释。

## 月度或阶段综合汇报

1. 标题与姓名
2. 月度摘要
3. 关键成果
4. 文献阅读与项目启示
5. 科研项目进展
6. 论文或专利进展
7. 学术交流及其他工作
8. 上期意见落实情况
9. 下一阶段计划
10. 参考文献

月度摘要优先写可量化成果和关键结论。文献阅读采用“文献结论—与当前项目的关系—可执行启示”的顺序。事务性内容保持简短。

## 多实验结果单元

同一报告包含多个数据集、模型或消融实验时，每个结果单元使用统一模板：

1. 一句话结果结论；
2. 实验对象与比较条件；
3. 结果表或图；
4. 关键数值和差异；
5. 当前证据范围；
6. 下一步验证。

相同的训练参数集中写一次。各实验只写变化项，避免重复。
